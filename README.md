### 🚀 About Me

I am a developer focused on designing and engineering interactive digital experiences. My work bridges **game development** (gameplay loops, mechanics, and interactive 3D/AR systems) and **modern full-stack web engineering** (clean architecture, responsive interfaces, and performant backends).

- 🎮 **Game Development**: Creating multiplayer systems, progression loops, and interactive simulations using **Roblox Studio (Lua)** and **Unity (C#)**.
- 💻 **Web Engineering**: Building accessible, performant web applications and developer tools with **TypeScript**, **Next.js**, **React**, and **Node.js**.
- 🛠️ **Approach**: Emphasizing clean code, responsive design, modular architecture, and intuitive user experiences.
